
# Distance & Unit Expander

## Description
This is a C program that converts distances between different units.

## Conversions Available
1. Kilometer to Meter
2. Kilometer to Centimeter
3. Meter to Kilometer
4. Meter to Centimeter
5. Centimeter to Meter
6. Centimeter to Kilometer
7. Mile to Kilometer
8. Kilometer to Mile
9. Feet to Meter
10. Meter to Feet
11. Inch to Centimeter
12. Centimeter to Inch

## Language Used
- C

## How to Run
Compile the program using a C compiler and run the executable.

## Example
Input:
5 miles

Output:
8.05 km
